# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、控制措施、安全说明、预期结果和依赖关系。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 修改步骤后自动计算全部下游步骤，提醒受影响的后续步骤和已确认内容。
- 自动识别存在危险项但缺少控制措施或安全说明的步骤，并阻止确认与冻结。
- **临时偏离许可（Deviation Permit）**：实验中途换材料或放宽控制时，先选择步骤与受影响字段，快照保存原值、临时值、原因、补偿性控制措施与生效起止时段。
  - 记录保存后即为**待审**，本步骤不能确认、被申请字段锁定；未通过或已过期持续拦截。
  - 复核人批准后临时值才写入步骤；本步骤及全部下游已确认内容打回重新复核，复核人同意后才恢复确认。
  - 被许可字段在生效期间发生许可外修改、许可被复核人撤销或生效时段到期：许可自动失效、临时值恢复原值、原确认立即标记失效并级联下游重新复核；需复核人显式「同意恢复」才能再次确认。
  - 每份许可保留完整审计时间线（申请、批准依据、退回、写入、撤回、到期、漂移失效、级联、恢复），重开页面与版本快照均随版留存；存在待审或拦截许可时禁止冻结。
- 提交复核后，复核人可逐条添加批注、标记解决、确认或退回。
- 所有步骤确认且安全信息完整后冻结版本；冻结后只能从该版本创建修订稿。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项、依赖等字段变化，并对照两版的偏离许可快照。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
